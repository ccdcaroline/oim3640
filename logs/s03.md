**Arithmetic** - use of symbols (ex. of operators +, -, *, /)

**Expression** - a collection of operators and numbers 

**Arithmetic Functions** - round(#) abs(#) This is calling the function, you need () to call it. 

**Strings (str)** - sequences of letters, dont use back quotes "Hello World" or 'Hello World' works (use "" for grammar purposes)  
To **join** strings together - **concatenation** use +. "well" + 'it's a' + 'small world' = "well it's a small world"  
To make **multiple** copies of strings - use *. 'spam,' * 4 = 'spam, spam, spam, spam,' 
To find **length** of string - len('spam') =  4 

2 = integer **(int)**   
42.9 = floating point number **(float)**       
To **find type** - type(2) = int 
To **convert type** - int(42.9) = 42 

**Operands** - the values in the expression. 

**TypeError** - means the values have the wrong type. 

Don't use commas to write large intergers, instead use **underscores** to make it easier to read. (EX. 1_000_000 = 1000000)

**Natural Language** - English, Spanish, French, evolved naturally. 
**Formal Language** - Languages designed by people, python. 

**Bugs** - Programming errors. **Debugging** - The process of tracking them down.

**Variable** - Name that refers to a value. Write an **assinment variable** to create a variable. (Ex. n = 17) **State Diagram** - n ---> 17
Variable names can have numbers and letters, but can't start with a number, **only punctuation** you can use is underscore, keywords can't be used for names. 

To use some features you need to **import** the module. 
**Module** - A collection of variables and functions. 
To use a variable from the module you need to use the **dot operator .** between the name of the module and the name of the variable. (Ex. math.pi = 3.14159..)

**Statement** - A unit of code that has an affect, but no value (Ex. n=17)

**Print Funciton - print()** - use it to display more than one value. 

**Argument** - When you call the funciton, it is the expression in the parenthesis. 

**Comments** - Notes intergrated into the code, use **#**. 

**Syntax Error** - Refers to structure and the rules. **Runtime Error** - Noy syntax errors so it starts running, but something goes wrong, an **exception**. 
**Semantic Error** - Related to a meaning.
