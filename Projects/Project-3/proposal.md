**What I'm building:** I am building a Flask web application that helps users find the nearest MBTA station based on a place name or address they enter.
**Why I chose this:** I chose this project because it creates something practical that people in the Boston area could actually use.
**Core features:** 
- A user can enter a place name or street address into a form on the website
- The app will use the Mapbox API to convert that location into coordinates
- The app will use the MBTA API to compare nearby stops and determine which one is closest
- The app will display the name of the nearest MBTA station and useful information about it
**What I don't know yet:** 
- How to properly connect Flask forms to API calls and then display the results on the page
- How to work with latitude and longitude data when comparing distances
- How to structure the app so it stays organized between routes, functions, and templates
