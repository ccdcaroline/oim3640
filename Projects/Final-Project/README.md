# OVERVIEW 
I created a web-based workout generator that allows users to quickly get a structured exercise routine. When someone visits the site, the app generates a simple workout with exercises, sets, and reps, making it easy to follow without any setup.The goal of the project was to create a simple, practical tool that helps people decide what workout to do quickly and efficiently.

# HOW TO USE 
To use this app, first make sure you have Python and pip installed on your computer. Then download the project files and install the required packages by running pip install -r requirements.txt in your terminal. You will also need to get API keys from OpenWeather and API Ninjas and add those keys to your environment variables. Once everything is set up, run the app, app.py, and open the local URL in your browser(or use the provided render deployed URL). When entering a weather location, make sure to format it as “City, US” instead of including the state, such as “Boston, US” instead of “Boston, MA.” After the app opens, you can edit the workout choices based on your preferences, such as the type of workout or options shown in the app, to create a workout that better fits what you want to do.
