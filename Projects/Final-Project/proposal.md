**What I'm building:** A web application that recommends personalized workouts based on user mood, goals, and real-time weather data.

**Why I chose this:** I often struggle to decide what workout to do based on how I feel and external factors like weather. This app solves that by making quick, personalized workout decisions easier and more structured. 

**Core features:** 
- User input for mood, energy level, and fitness goals
- Integration with a weather API to adjust recommendations
- Exercise suggestions pulled from an external fitness API
- Clean interface displaying a daily workout plan
- Option to refresh for new recommendations
**What I don't know yet:** 
- An exercise API 
- How to get mutliple options 
- How many exercises per workout 
- How to fully deploy a flask app
